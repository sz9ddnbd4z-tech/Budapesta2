BUDAPESZT, NA DWOJE — V2

To jest wersja HOSTOWANA, przygotowana pod iPhone/Safari.
Nie otwieraj index.html jako pliku z aplikacji Pliki, bo wtedy Safari/Quick Look
może blokować część funkcji JavaScript i zewnętrzne zasoby mapy.

Pliki:
- index.html — aplikacja
- manifest.webmanifest — instalacja jako aplikacja WWW
- sw.js — cache aplikacji
- icon.svg — ikona

Najprościej:
1. Utwórz repozytorium na GitHub.
2. Wrzuć wszystkie 4 pliki do głównego katalogu.
3. Włącz Settings → Pages → Deploy from branch → main / root.
4. Otwórz otrzymany adres HTTPS na iPhonie w Safari.
5. Udostępnij → Do ekranu głównego → Otwórz jako aplikację www.

GitHub Pages automatycznie obsługuje HTTPS.
